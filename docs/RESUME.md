**基于 LangGraph 与 RAG 的多 Agent 旅游规划系统｜Python 二次开发**

项目介绍：基于开源旅游规划系统扩展 Python 后端，通过多 Agent 协作完成偏好处理、目的地推荐、航班与酒店候选比选、活动安排和预算校验，并加入旅游资料检索、引用摘要与任务进度推送。

技术栈：Python / FastAPI / LangGraph / asyncio / Pydantic / Qdrant / Redis / HTTPX / SSE / Docker / pytest。

- 基于 LangGraph 构建“偏好收集 → 目的地推荐 → 四分支检索与比选 → 预算校验 → 资料摘要”流程，采用独立状态通道汇合结果，支持有界预算回路、工具超时与有限重试。
- 构建 Qdrant 资料检索链路，实现文本切分、城市过滤、向量召回、关键词二阶段重排和来源引用，通过稳定文档标识处理重复上传及短版本替换。
- 修复预算调整被重新搜索覆盖的问题，在原有候选集中逐轮调整活动、酒店与航班，保留候选报价，超过最大轮次后返回明确的约束不可行状态。
- 基于 Redis 保存任务快照、执行事件与工具缓存，使用 Lua 原子更新任务状态和事件序号，为状态查询及事件回放提供一致存储。
- 使用 SSE 推送节点完成进度，支持 Last-Event-ID 游标重放，将执行任务与订阅连接分离，支持断线后查询结果及重连进度。
- 提供可配置模型摘要接口，对 JSON 结构与引用 ID 进行校验和有限修复，通过自动化测试覆盖并行执行、预算回路、缓存、RAG 过滤及 SSE 重连。

当前旅行报价为模拟数据，默认检索为 hash 基线，重排为关键词算法；真实模型及语义向量服务的实测结果需完成接入后补充。
